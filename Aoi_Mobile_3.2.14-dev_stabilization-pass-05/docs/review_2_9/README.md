# Aoi 2.9.0 visual review

All captures are 720 × 1520 Godot 4.8 beta1 renders using the GL Compatibility renderer and an isolated local profile.

- `explore_720x1520.png` — Explore category chips now wrap instead of clipping off the right edge.
- `studio_720x1520.png` — Aoi Studio Sources view with persistent bottom composer and local project tree.
- `studio_api_720x1520.png` — mobile API Explorer: live class list, search, and details area.
- `pc_companion_720x1520.png` — optional PC companion plan with setup and security limitations.

These are desktop-engine phone-sized renders, not physical Android screenshots. The first draft of the API Explorer and PC companion dialogs had dark backgrounds and clipped content; the final captures show the corrected white full-rect panels and scrollable layout.
