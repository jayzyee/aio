# Aoi 2.8.0 — Studio review captures

All images were captured from the Godot 4.8 beta1 runtime at 720 × 1520 using a virtual X11 display and llvmpipe.

- `chat_720x1520.png` — Aoi Studio Chats state, floating build activity indicator, and bottom composer.
- `sources_720x1520.png` — Sources state, project identity, Add Sources/New Script actions, project file tree, toolbox hint, and retained composer.
- `activity_720x1520.png` — expanded Plan → Build → Run → Review activity panel above the composer.
- `workflow_720x1520.png` — specialist workflow board with roles, stage sequence and task execution surface.

These are engine-rendered desktop captures at a phone-sized viewport. They are not captures from a physical Android device. The dummy audio-driver fallback shown in the engine log is an environment limitation, not a UI failure.
