# Aoi 3.2.5 visual checkpoint — historical recovery record

This document records the previous packaging mistake and is retained for traceability. The 3.2.5 visual work has since been reimplemented in the 3.2.6 recovered Godot source.

## What the earlier 3.2.5 ZIP contained
- The 3.2.3-dev Godot source baseline, unchanged.
- The 3.2.5 motion/type/icon direction board.
- 720 × 1520 review captures.

## Recovery status
The 3.2.5 design direction is now implemented in source files in 3.2.6: `scripts/ui/AoiSignalField.gd`, `AoiPresence.gd`, `BuildExperienceCard.gd`, `Ui.gd`, `ChatScreen.gd`, `SetupScreen.gd`, and the Aoi/app icon assets. The actual creation screen was recaptured from the Godot project at 720 × 1520. See `docs/RECOVERY_LEDGER_3.2.6.md`.

## Remaining lineage limitation
The 3.2.4 archive remains preserved in Dropbox at `/Aoi/Aoi_Mobile_3.2.4-dev_Godot4.8beta1.zip`, but its source diff could not be materialized in this environment. Therefore 3.2.6 is explicitly a recovered extension of the local 3.2.3 source, not a verified merge of 3.2.4.

The creation-card screenshots are presentation fixtures, not evidence of a live game build or playable runtime.
