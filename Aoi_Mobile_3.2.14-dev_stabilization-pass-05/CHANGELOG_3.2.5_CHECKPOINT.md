# Aoi 3.2.5 recovery record

This folder began from the locally retained 3.2.3-dev project package because the 3.2.4 archive remained stored in Dropbox but could not be downloaded into this container. The 3.2.4 archive is preserved at `/Aoi/Aoi_Mobile_3.2.4-dev_Godot4.8beta1.zip`.

The 3.2.5 design direction and evidence were recovered from the prior checkpoint: Spatial Prism (chosen), Inter Variable type hierarchy, motion/typography/icon board, and 720 × 1520 review captures. The prior 3.2.5 ZIP itself did not contain source changes: its project files were byte-identical to 3.2.3, with only the direction board and two screenshots added.

The next working source therefore carries the explicit version `3.2.6-dev` and integrates the recovered design decisions into a real Godot source tree. No claim is made that the unavailable 3.2.4 source diff was merged.
